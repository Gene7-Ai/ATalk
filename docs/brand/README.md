# ATalk brand assets

- `atalk-lockup-{light,dark}.{svg,png}` — mark + wordmark + tagline, transparent background (README uses the PNG: GitHub mobile renders SVG at intrinsic size)
- `atalk-mark-{light,dark}.svg` — mark only (four triangles: A ▲ / T ▽ / K ▲▲)
- `atalk-mono-{ink,white}.svg` — single-colour mark, 1px separations
- `favicon.svg` — night tile

Wordmark and tagline are outlined paths (no font dependency). Colours: mint `#7ee0c3`, gold `#ffd479`, deep teal `#3d7a6a`, night `#0b1020`, ink `#1a2540`.
