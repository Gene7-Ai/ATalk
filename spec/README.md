# ATalk Protocol specification

- **[ATalk Protocol 0.9 (draft for comment)](atalk-protocol-0.9-draft.md)**, published 2026-10-17.

This is a **draft for public comment, not a frozen standard**. Version 1.0 will be frozen only after the specification, the reference implementation and a conformance suite agree, and comments received during the comment period have documented resolutions.

## How to comment

Open a GitHub issue in this repository and put `[spec]` at the start of the title. Please cite the requirement ID you are commenting on (for example `ATP-ACK-05`). The comment period is at least 14 days from publication.

## Status of the reference implementation

ATalk 0.3.0a7 (commit dec3312) is the implementation baseline used to inform this draft. It is **not certified conformant**. Known deviations are listed in Appendix A of the draft. A black-box conformance suite is planned (Appendix B) and has not been run yet.
